Gestion des locaux

Web

Application web pour la gestion des locaux avec Flask et MySQL.

À propos du projet

Cette application permet de gérer les locaux d'une structure : réservation, suivi des disponibilités, utilisateurs et historique des réservations. Le projet a été développé avec Flask et une base de données MySQL, et testé sur Google Colab.

Fonctionnalités principales

  • ✓ Gestion des utilisateurs
  • ✓ Réservation des locaux
  • ✓ Statistiques en temps réel
