Gestion de bibliothèque

Java & BDD

Système de gestion de prêt de livres avec base de données MySQL.

À propos du projet

Application complète pour la gestion des ouvrages, des adhérents et du cycle de prêt dans une bibliothèque universitaire. Conçue avec Java et connectée à une base de données relationnelle MySQL pour assurer l'intégrité et la persistance des données.

Fonctionnalités principales

  • ✓ Catalogue d'ouvrages avec recherche multi-critères
  • ✓ Gestion des emprunts, retours et alertes de retard
  • ✓ Gestion des fiches lecteurs et historique des prêts
